# Tic Tac Toe Game

A simple JavaScript Tic Tac Toe game where two players take turns placing X and O on the board.

## About the Project

This is a beginner JavaScript project built to practice:

- JavaScript basics
- DOM manipulation
- Event listeners
- Arrays
- Conditional statements (if, else)
- Functions
- Game logic

The game allows two players to play Tic Tac Toe by taking turns. It checks for winning combinations, tie situations, and displays the current game status.

## Features

- Two-player gameplay (X and O)
- Turn-based system
- Win detection logic
- Tie game detection
- Reset button to restart the game
- Dynamic game status updates

## Technologies Used

- HTML5
- Tailwind CSS
- JavaScript

## How to Run

Clone this repository:

```bash
git clone [<repository-link>](https://github.com/Priyanka-Popat/Tic-Tac-Toe-JS.git)
```

Open the project folder:

```bash
cd tic-tac-toe
```

Open `index.html` in your browser.
